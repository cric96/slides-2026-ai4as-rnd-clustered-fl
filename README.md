# AI4AS 2026 — Presentation

Slidev deck for **AI4AS 2026**, presented on **Monday, 7 September 2026** *(tomorrow)*.

**Title:** *Discovering Collaboration from Novelty: Random Network Distillation for Clustered Federated Learning*

**Purpose:** present a lightweight, data-free clustering mechanism that helps federated-learning clients collaborate under non-IID data distributions, using traffic forecasting as the motivating scenario.

**Authors:** Davide Domini · Gianluca Aguzzi · Ivana Dusparic · Danilo Pianini · Mirko Viroli
